# SMERP v2 — PRD (Product Requirements Document)

> 서버메이트 ERP 시스템 — 견적서/품의서/발주서/계산서/경영관리

## 1. 프로젝트 개요

### 1.1 배경
서버메이트는 서버/네트워크 장비 판매 및 유지보수(MA) 서비스를 제공하는 회사.
기존에 엑셀로 관리하던 견적서, 품의서, 발주서, 계산서 발행, 매출/매입 장부를 웹 ERP로 전환.

### 1.2 핵심 사용자
| 역할 | 설명 | 주요 기능 |
|------|------|-----------|
| **영업 담당자** | 견적서 작성, 품의서 기안, 발주서 발행 | 문서 CRUD, 엑셀 업로드/다운로드 |
| **영업 팀장** | 품의서 1차 결재 | 결재 승인/반려 |
| **대표이사 (CEO)** | 품의서 최종 결재 | 결재 승인/반려 |
| **경영팀** | 매출/매입 관리, 계산서 발행 추적, 입출금 관리 | 매출장/매입장, 계산서 현황, 통계 |
| **MA 담당자** | 유지보수 견적서/품의서 관리 | MA 문서 CRUD |
| **관리자** | 사용자/권한 관리, 시스템 설정 | 유저 관리, 엑셀 양식 관리 |

### 1.3 기술 스택
- **프론트엔드**: Next.js 14 (App Router) + TypeScript + Tailwind CSS
- **백엔드**: Next.js API Routes
- **DB**: PostgreSQL (AWS RDS)
- **ORM**: Prisma
- **스토리지**: AWS S3 (파일 첨부, 서명 이미지)
- **인증**: 세션 기반 (NextAuth)

## 2. 문서 체계

### 2.1 영업 (Sales) 문서 플로우
```
견적서(Quote) → 품의서(Approval) → 발주서(Order)
                    ↓
              결재 (팀장→CEO)
                    ↓
              계산서 발행 추적
```

#### 2.1.1 영업 견적서 (Sales Quote)
- **구조**: 제품 그룹(Product) > 품목(Item) 2단계
  - 제품: "영상편집용 조립PC" 같은 묶음 단위
  - 품목: CPU, RAM, SSD 등 개별 부품
- **매출 정보**: 제품 단위 매출단가/합계
- **고객 정보**: 회사명, 담당자, 전화, 팩스, 휴대폰, 이메일
- **조건**: 견적일, 유효기간, 납기일, 결제조건
- **엑셀 연동**: 기존 엑셀 양식 업로드 → 파싱 → 폼 매핑
- **상태**: DRAFT → SENT → ACCEPTED/REJECTED
- **버전 관리**: 수정 시 새 버전 생성 (원본 보존)

#### 2.1.2 영업 품의서 (Sales Approval)
- **문서번호**: 자동채번 (SA-2025-0001) + 품의코드 (D251206-01)
- **구조**: 제품(Product) > 품목(Item) 2단계
  - 제품: 매출 단위 (= 매출 계산서 단위)
  - 품목: 개별 부품 + **매입 정보** (매입처, 매입단가, 매입합계)
- **금액**: 매출합계, 매입합계, 이익(매출-매입) 자동 계산
- **결재 3단계**: 영업담당자 서명 → 영업팀장 서명 → CEO 서명
- **상태**: DRAFT → PENDING_TEAM_LEAD → PENDING_CEO → APPROVED / REJECTED
- **회수(Withdraw)**: 결재 중 작성자가 회수 → 새 DRAFT 버전 생성
- **수정(Revise)**: 승인 후에도 수정 가능 → 새 버전 (계산서 추적)
- **계산서 추적**: 제품별 매출 계산서, 품목별 매입 계산서 발행 상태
- **견적서 연결**: 견적서 기반으로 품의서 생성 가능

#### 2.1.3 영업 발주서 (Sales Order)
- **문서번호**: 자동채번 (SO-2025-0001)
- **구조**: 단순 품목 리스트 (1단계)
- **매입처 정보**: 회사명, 담당자, 전화, 이메일
- **금액**: 공급가, 부가세, 합계
- **상태**: DRAFT → SENT → CONFIRMED → DELIVERED / CANCELLED

### 2.2 MA (유지보수) 문서 플로우

#### 2.2.1 MA 견적서 (MAQuote)
- 장비별 유지보수 견적 (기기명, 모델, S/N, 서비스레벨, 기간, 금액)
- 서비스 약관, 특약사항

#### 2.2.2 MA 품의서 (MAApproval)
- 매출/매입 대비표 구조
- 고객사, 유지보수 기간, 청구구분(일시불/월간/분기)
- 매출가 vs 매입가 비교

## 3. 경영관리

### 3.1 매출장 (Sales Ledger)
- 품의코드, Vendor코드, 거래일, 매출처, END-USER
- 구분: MA, 상품, 건물임대, 장비임대
- 금액: 수량, 단가, 공급가, 부가세, 합계, GP
- 결제상태/예정일, 담당자

### 3.2 매입장 (Purchase Ledger)
- 품의코드, Vendor코드, 계산서발행일, 매입처, 매출처
- 구분: MA, 상품, 일반경비
- 금액, 결제상태, 유형(세금계산서/현금/카드/수입)

### 3.3 계산서 발행 현황
- 품의코드별 매출/매입 계산서 통합 뷰
- 발행상태 추적, revision 연동

### 3.4 통계/리포트
- 월별 매출/매입 요약, 담당자별 랭킹, 연간 보고서
- 외상매출 입금예정 / 외상매입 출금예정

## 4. 시스템 기능

### 4.1 사용자/권한
- 부서, 직급, 역할, 메뉴별 권한(NONE/READ/FULL)
- 서명 이미지(S3), 연차 관리

### 4.2 거래처
- 매출처(Customer) + 담당자 목록
- 매입처(Vendor)

### 4.3 엑셀 양식 관리
- 문서 타입별 양식 등록, 필드/열 매핑

### 4.4 알림
- 결재 요청/승인/반려, MA 만료, 결제 예정

### 4.5 캘린더 + 휴가
- 개인/전체 일정, 연차/반차/병가
