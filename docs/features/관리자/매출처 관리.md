# 매출처 관리 🟢

거래하는 고객사(매출처)를 등록하고 관리한다. 회사별 다중 담당자 관리를 지원하고, 견적서/품의서 작성 시 고객사 선택 모달에서 참조된다.

**진행률** ████████████████████ 100%

## 사용자 플로우

1. 매출처 목록에서 회사명 검색
2. 신규 매출처 등록 (회사명, 전화, 팩스, 주소, 비고)
3. 상세 페이지에서 담당자 추가/수정 (이름/부서/직급/전화/휴대폰/이메일)
4. 기본 담당자 지정 (`isDefault`)

## 완료

- ✅ 매출처 CRUD
- ✅ 회사명 검색
- ✅ 담당자 다중 관리 (CustomerContact)
- ✅ 기본 담당자 지정
- ✅ 상세 페이지
- ✅ 신규 등록 모달

없음.
