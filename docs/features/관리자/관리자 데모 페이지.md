# 관리자 데모 페이지 🟢

사내 관계자(경영진/신규 유저)에게 SMERP 프로젝트를 소개하기 위한 정적 발표용 페이지 모음이다. 실제 업무 기능은 아니며 슬라이드형 설명으로만 구성된다.

**진행률** ████████████████████ 100%

## 사용자 플로우

1. `/admin/project-intro`에서 프로젝트 개요, 목적, 기술 스택 소개 확인
2. `/admin/process-demo`에서 슬라이드 네비게이션으로 영업 문서 처리 프로세스 단계 시연
3. `/admin/system-architecture`에서 문서 간 데이터 흐름과 시스템 구조도 확인

## 완료

- ✅ 프로젝트 소개 페이지 (정적)
- ✅ 영업 문서 처리 프로세스 슬라이드 데모 (useState 기반 슬라이드 전환)
- ✅ 시스템 구조도 페이지 (Deal → 견적 → 품의 → 발주 → 원장 흐름 시각화, 2026-04-21 InvoiceRecord 기반 구조 반영)

없음.
