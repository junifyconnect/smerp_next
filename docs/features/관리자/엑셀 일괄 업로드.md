# 엑셀 일괄 업로드 🟢

엑셀 파일을 드래그앤드롭으로 업로드해 견적서/품의서/발주서를 일괄 생성한다. 문서 타입을 자동 감지하거나 수동 선택할 수 있다.

**진행률** ████████████████████ 100%

## 사용자 플로우

1. 엑셀 파일을 드래그앤드롭 또는 파일 선택으로 업로드
2. 문서 타입 자동 감지 또는 수동 선택 (견적서/품의서/발주서/MA견적서/MA품의서)
3. 각 타입의 upload API를 통해 파싱·생성
4. 업로드 결과 확인 (성공/실패 파일별 docNumber 또는 에러 메시지, 감지된 타입)

## 완료

- ✅ 다중 파일 업로드
- ✅ 드래그앤드롭
- ✅ 문서 타입별 파싱 (5종: SALES_QUOTE/SALES_APPROVAL/SALES_ORDER/MA_QUOTE/MA_APPROVAL)
- ✅ 업로드 결과 표시 (성공/실패/감지된 타입)
- ✅ 등록된 ExcelTemplate 기반 동적 파싱 (`dynamic-parser.ts`)

## 남은 것

없음.
