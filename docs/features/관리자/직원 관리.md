# 직원 관리 🟢

관리자가 직원 계정을 관리한다. 부서별 분류, 역할/메뉴 권한 설정, 연차 부여를 지원한다. 2026-04-22 PR #11로 `GET /api/users`에 `isActive` / `role` 쿼리 필터가 추가되어 `<ApprovalLineModal>`(영업/MA 품의서 결재선 지정 모달)이 활성 사용자·특정 역할을 필터해 조회할 수 있다.

**진행률** ████████████████████ 100%

## 사용자 플로우

1. 직원 목록에서 부서별 필터로 조회
2. 직원 상세에서 역할 부여 (ADMIN / SALES_MANAGER / SALES_STAFF / MA_MANAGER / MA_STAFF / FINANCE)
3. 메뉴별 권한 설정 (NONE / READ / FULL) — SALES_QUOTE, SALES_APPROVAL, SALES_ORDER, MA_QUOTE, MA_APPROVAL, CLOUD, USER_MANAGEMENT 등
4. 연차/추가휴가 부여
5. 직원 활성/비활성 관리

## 완료

- ✅ 직원 목록 CRUD
- ✅ 부서별 분류 표시 (SALES/MA/FINANCE/ADMIN)
- ✅ 역할 관리 (UserRole 다대다)
- ✅ 메뉴별 권한 설정 (UserMenuPermission)
- ✅ 연차/추가휴가 부여
- ✅ 직원 활성/비활성 관리 (`isActive`)
- ✅ `GET /api/users` 필터 — `?isActive=true|false`, `?role=TEAM_LEADER` 등 (2026-04-22 PR #11, ApprovalLineModal용)

## 남은 것

없음.

## 관련 화면

- `/admin/users` (직원 목록, 부서별 필터, 연차 부여)
- `/admin/users/[id]` (직원 상세 — 역할/메뉴 권한 관리)
