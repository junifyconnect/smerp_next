# 매입처 관리 🟢

거래하는 공급사(매입처)를 등록하고 관리한다. 발주서/품의서 작성 시 자동완성(VendorAutocomplete)으로 연동된다.

**진행률** ████████████████████ 100%

## 사용자 플로우

1. 매입처 목록에서 이름 검색
2. 신규 매입처 등록 (이름, 담당자, 전화, 이메일, 비고)
3. 발주서/품의서 작성 시 자동완성으로 매입처 선택 (선택 시 `usageCount` 증가)

## 완료

- ✅ 매입처 CRUD
- ✅ 이름 검색
- ✅ 사용 횟수(`usageCount`) 기반 정렬
- ✅ 자동완성 컴포넌트 (`VendorAutocomplete`) — 발주서/품의서에서 공유 사용

## 남은 것

없음.
