# 엑셀 양식 관리 🟢

엑셀 파싱에 사용할 양식(템플릿)을 등록하고 관리한다. 문서 타입별로 필드 매핑, 품목 테이블 범위, 매출/매입 열 매핑을 설정한다.

**진행률** ████████████████████ 100%

## 사용자 플로우

1. 양식 목록에서 문서 타입별 양식 조회
2. 신규 양식 등록 시 샘플 엑셀 업로드 → 자동 분석(`analyze`) API로 구조 파악
3. 필드 매핑 설정 (셀 좌표 지정 — 예: approvalCode → "D9")
4. 품목 테이블 헤더/데이터 시작/종료 행 설정
5. 매출/매입 열 매핑 (예: partNumber → "C")
6. 해당 docType의 기본 양식(`isDefault`) 지정

## 완료

- ✅ 양식 CRUD
- ✅ 문서 타입별 분류 (5종)
- ✅ 필드 매핑 설정 (JSON 저장)
- ✅ 품목 테이블 범위 설정 (헤더/시작/종료 행)
- ✅ 매출/매입 열 매핑
- ✅ 샘플 파일 분석 API
- ✅ docType별 기본 양식 고유 제약(`@@unique([docType, isDefault])`)

## 남은 것

없음.

## 관련 화면

- `/admin/excel-templates` (양식 목록)
- `/admin/excel-templates/new` (신규 양식 등록)
- `/admin/excel-templates/[id]` (양식 상세)
