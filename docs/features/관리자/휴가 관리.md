# 휴가 관리 🟢

직원들의 휴가 신청을 관리한다. 다양한 휴가 유형, 자동 승인, 연차 차감 여부 설정을 지원한다.

**진행률** ████████████████████ 100%

## 사용자 플로우

1. 직원이 휴가 신청 (유형/기간/사유 입력)
2. 자동 승인 처리 (`LeaveStatus.APPROVED` 기본)
3. 관리자가 휴가 목록에서 타입별 필터로 조회
4. 필요 시 취소 처리 (`cancelledAt` 기록)

## 완료

- ✅ 휴가 신청/조회
- ✅ 타입별 분류 (연차/오전반차/오후반차/병가/경조사/공가/기타)
- ✅ 자동 승인 방식
- ✅ 연차 차감 여부 설정 (`deductFromAnnual` — 병가/공가 등은 미차감)
- ✅ 취소 처리

## 남은 것

없음.
