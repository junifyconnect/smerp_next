# 경영 통계 🟢

연간 매출/매입/GP 통계, 거래처별 순위, 월말 입출금 예측 등 경영진용 리포트 API를 제공한다. 2026-04-22 PR #14로 **영업(SalesLedger/PurchaseLedger) + MA(MABilling) 통합 집계**가 구현되어 MA 매출/매입이 누락되지 않는다 (BUSINESS_RULES §10.1). 원장의 `isActive` 필터를 일관 적용해 revise 체인에서 안전하다. API는 완성되어 있고, UI 방향은 별도 리포트 페이지(`/management/reports`)로 확정 — 차트 라이브러리 도입 및 리포트 레이아웃 설계가 남아 있다.

**진행률** ███████████████░░░░░ 75%

## 제공 기능

- 연간 매출/매입/GP 집계 리포트 (월별 추이, 카테고리별, 담당자별) — **영업 + MA 통합**
- 매출처/매입처별 거래 순위 + 점유율
- 월말 기준 외상매출금(receivables)/외상매입금(payables) 예측 + 순현금흐름

## 완료

- ✅ 연간 리포트 API — 총매출/총매입/GP, 월별 추이(12개월), 카테고리별 집계, 담당자별 매출
- ✅ **영업 + MA 통합 집계** (PR #14):
  - `totalSales` / `totalPurchase`에 `breakdown: { salesApproval, maBilling }` 추가 — 출처별 분해 제공
  - `byCategory`에 MA 포함 — MABilling의 `supplyAmount` 합산
  - 월별 추이: SalesLedger는 `transactionDate`, MABilling은 `dueDate` 기준으로 월 버킷팅
- ✅ 회사별 매출/매입 순위 API — 기간 파라미터, 순위별 점유율(sharePercent) 계산
- ✅ 월별 입출금 예측 API — 결제예정일 기준 receivables/payables, 업체별 그룹핑, netCashFlow
- ✅ 모든 집계 쿼리에 `isActive: true` 필터 일관 적용 — revise 체인 정합성 보장 (SalesLedger/PurchaseLedger/MABilling 모두)
- ✅ GP 계산 fallback (grossProfit 필드 없으면 매출-매입 차액으로 대체)
- ✅ UI 방향 확정 (별도 리포트 페이지 `/management/reports`. 대시보드에는 통합하지 않음 — 결정대기 #4 별도 논의)

## 남은 것

- ❌ `app/(main)/management/reports/` 페이지 생성 (경영 리포트 라우트)
- ❌ 차트 라이브러리 선정 및 도입 (recharts 또는 Chart.js)
- ❌ 연간 매출/매입/GP 리포트 뷰 (영업/MA breakdown 시각화 포함)
- ❌ 회사별 순위 테이블/차트 (top N, sharePercent 시각화)
- ❌ 월별 예측 차트 (receivables/payables/netCashFlow)
- ❌ 사이드바 메뉴에 "경영 리포트" 추가
- ❌ 기간 비교(전년 동기 대비 등) 분석
- ❌ 회사 순위 / 월별 예측 API도 MA UNION으로 확장 (현재 annual-report만 통합 완료)

## API 엔드포인트

- `GET /api/management/stats/annual-report?year=YYYY` — **영업 + MA 통합** 연간 매출/매입/GP + 월별·카테고리별·담당자별 집계, breakdown 포함
- `GET /api/management/stats/company-rank?type=sales|purchase&startDate&endDate&limit` — 거래처 순위 + 점유율
- `GET /api/management/stats/monthly-forecast?year&month` — 해당 월 외상매출/매입 예측 + 순현금흐름
