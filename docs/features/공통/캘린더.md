# 캘린더 🟢

월간 캘린더 뷰에서 일정을 조회하고 관리한다. 개인/전체/회의/마감/휴일 등 다양한 일정 타입과 참여자 관리를 지원한다.

**진행률** ████████████████████ 100%

## 사용자 플로우

1. 캘린더 페이지에서 월간 뷰로 일정 확인 (공휴일 표시 포함)
2. 날짜 클릭으로 일정 생성 모달 열기
3. 일정 타입 선택 (PERSONAL / COMPANY / MEETING / DEADLINE / HOLIDAY / MA_EXPIRY / PAYMENT_DUE)
4. 종일/시간 지정, 참여자 선택, 색상 지정, 알림 시간 설정
5. 기존 일정 클릭으로 수정/삭제

## 완료

- ✅ 월간 캘린더 뷰
- ✅ 일정 CRUD (개인/전체/회의/마감/휴일)
- ✅ 공휴일 API (`/api/calendar/holidays`)
- ✅ 일정 타입별 색상 구분
- ✅ 종일/시간 지정 이벤트
- ✅ 참여자 관리 (`CalendarEventParticipant`)
- ✅ 회사 전체 공개 일정(`isCompanyWide`)
