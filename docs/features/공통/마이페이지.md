# 마이페이지 🟢

본인의 정보 조회, 비밀번호 변경, 서명 이미지 업로드, 잔여 연차 확인 기능을 제공한다. 서명 이미지는 품의서 결재 시 서명란에 표시된다.

**진행률** ████████████████████ 100%

## 사용자 플로우

1. 마이페이지에서 본인 정보 확인 (사번/이메일/이름/부서/직급/역할)
2. 비밀번호 변경 (현재 비밀번호 확인 필수)
3. 서명 이미지 업로드 (결재 시 사용 — `signatureUrl`이 S3 키로 저장됨)
4. 연차/추가휴가 잔여일 확인

## 완료

- ✅ 사용자 정보 표시
- ✅ 비밀번호 변경 (bcrypt 비교)
- ✅ 서명 이미지 업로드 (S3 업로드 + signatureUrl 저장)
- ✅ 연차/추가휴가 잔여 표시
