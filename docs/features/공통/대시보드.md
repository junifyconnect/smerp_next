# 대시보드 🔴

로그인 후 첫 화면. 통계 카드 4종(총 견적서/승인 대기/이번달 매출/이번달 발주)과 최근 견적서·승인 대기 목록을 표시한다. 현재 전체가 하드코딩된 임시 데이터로만 동작하며 실제 DB 연동은 미구현 상태다.

**진행률** ██░░░░░░░░░░░░░░░░░░ 10%

## 예상 사용자 플로우

> 현재는 임시 데이터만 보여줍니다. 아래는 최종 구현 예상 흐름입니다.

1. 로그인 후 대시보드 진입
2. 통계 카드 4종 확인 (총 견적서 / 승인 대기 / 이번달 매출 / 이번달 발주)
3. 최근 견적서 목록 확인
4. 승인 대기 품의서 목록 확인

## 기반

- ✅ 페이지 레이아웃 (Server Component + Client Component 분리)
- ✅ 통계 카드 4종 UI
- ✅ 최근 견적서 목록 UI
- ✅ 승인 대기 목록 UI
- ✅ Server Action 스켈레톤 (`getDashboardStats` — next-safe-action + actionAuth)

## 필요한 것

- ❌ 실제 DB 데이터 조회 (현재 `getDashboardStats.ts`에 `// TODO: 실제 API 연동` 주석 + 하드코딩 데이터)
- ❌ 경영 통계 API 연동 (`/api/management/stats/*`)
- ❌ 승인 대기 품의서 쿼리 (role 기반 필터링)

## 관련 화면
