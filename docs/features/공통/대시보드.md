# 대시보드 🟢

로그인 후 첫 화면. `User.department` 기반으로 **영업팀 / 경영팀 / CEO** 세 가지 뷰를 분기 렌더링한다. 결정대기 #4 A안 확정(2026-04-23)에 따른 역할별 뷰.

**진행률** ██████████████████░░ 90%

## 사용자 플로우

1. 로그인 후 `/dashboard` 진입
2. 서버가 세션의 `User.department`를 읽어 역할 결정:
   - `ADMIN` → 경영진(CEO) 뷰
   - `FINANCE` → 경영팀 뷰
   - `SALES` / 기타 / null → 영업팀 뷰(기본값)
3. 역할에 맞는 위젯 세트 렌더링

## 역할별 뷰 구성

### 🧑‍💼 영업팀 (department=SALES, 기본)
- **상태 카드 4종**: 작성중 / 결재 진행 중 / 이번달 승인 / 반려 (내가 작성한 품의서 기준)
- **이번달 내 매출**: `SalesLedger` WHERE `managerName=내 이름` 합계
- **이번달 승인 건수**: 내가 작성한 APPROVED 품의서 count
- **결재 진행 중 품의서**: PENDING/PENDING_TEAM_LEAD/PENDING_CEO 최근 5건
- **최근 반려된 품의서**: REJECTED + rejectionReason 최근 5건

### 🧾 경영팀 (department=FINANCE)
- **상태 카드 4종**: 매출 발행 대기 / 매입 발행 대기 / 수정 필요(NEEDS_AMENDMENT) / 연체 합계
- **외상매출금**: SalesLedger + MABilling `paymentStatus=PENDING` 합계
- **연체 건수**: `paymentDueDate < today AND paymentDate IS NULL`
- **이번달 MA 청구 예정**: MABilling `dueDate` 이번달 목록 (20건까지, dueDate 오름차순)

### 👔 CEO (department=ADMIN)
- **연간 지표 카드 4종**: 총 매출 / 총 매입 / 매출총이익 / GP율 (영업 + MA UNION)
- **월별 매출 추이 차트**: 바 차트 12개월
- **담당자별 매출 순위**: SalesLedger `groupBy(managerName)` top 5
- **거래처별 매출 순위**: SalesLedger `groupBy(clientCompany)` top 5
- **내 결재 대기 품의서**: `status=PENDING_CEO` 최근 10건 (영업+MA 병합)

### 🔄 공통 (모든 역할 하단)
- **읽지 않은 알림** 카운트
- **오늘의 일정** (CalendarEvent: 개인 + 전사 공개)

**Entry points**
- `app/(main)/dashboard/page.tsx` — Server Component, `getDashboardStats` 호출
- `app/(main)/dashboard/_actions/getDashboardStats.ts` — 역할별 DB 집계 server action

  - `buildSalesDashboard` / `buildFinanceDashboard` / `buildCeoDashboard` 3종 빌더
  - `getCommonWidgets` — 알림/캘린더 공통
- `app/(main)/dashboard/_client/DashboardPageClient.tsx` — `role` 필드 기반 분기 렌더 (`SalesView` / `FinanceView` / `CeoView`)
- `app/(main)/dashboard/_types/dashboard.ts` — Discriminated union 타입

**주요 라이브러리**: next-safe-action (인증 미들웨어 + Zod 입력 검증)

**의존성 서비스**: PostgreSQL (Prisma)
- SalesLedger / PurchaseLedger / MABilling (집계)
- SalesApproval / MAApproval (내 품의서·CEO 결재 대기)
- InvoiceRecord (경영팀 발행 대기)
- Notification / CalendarEvent (공통)

**역할 매핑 규칙** (BUSINESS_RULES §5 결재선 규칙과 독립적):
| User.department | 뷰 |
|---|---|
| ADMIN | CEO |
| FINANCE | 경영팀 |
| SALES / null / 기타 | 영업팀 |

영업/MA 품의서 작성자는 대부분 SALES. 팀장(role=TEAM_LEADER) 역시 SALES department가 일반적이라 영업팀 뷰를 공유.
