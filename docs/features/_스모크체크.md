## 총평

- **모든 핵심 플로우 작동**: 마스터 등록 → 품의서 생성 → 3단계 결재 → 원장·InvoiceRecord 자동 생성 → 계산서 발행 → 수정발행 → 취소발행까지 전체 파이프라인 통과.
- **재설계 정합성 확인**: InvoiceRecord가 단일 진실 소스로 매출/매입 모두 품의서 승인 시 자동 생성되고, AMEND 시 원본 CANCELLED + 신규 PENDING 체인 연결 정상.
- **S3 실제 업로드 작동**: 서명 이미지가 실제 AWS S3 버킷에 올라가고 presigned URL 반환됨.
- **VAT 계산 정확**: TAX 10% / ZERO / EXEMPT 분기 설계대로 동작.

## 발견된 이슈

1. ⚠️ **API 필드명 불일치**: Customer는 `companyName`, Vendor는 `name`. 거래처 계열인데 스키마 통일 안 됨.
2. ⚠️ **invoice-status 500 에러 (파라미터 잘못 넘긴 경우)**: `?year=&month=` 형태로 호출하면 `new Date("Invalid Date")` 생성 후 Prisma에 그대로 전달되어 500. 파라미터 검증 추가 권장.
3. 🟡 **대시보드 하드코딩**: 샘플 데이터(156건/245,000,000원 등)가 그대로 표시됨 — spec에 미착수 10%로 명시된 대로.
