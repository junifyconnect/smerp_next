# 알림 🟢

결재 워크플로우 알림, 헤더 알림 벨, 읽음 처리 등 사내 알림 시스템을 제공한다. 다른 기능(영업 품의서 등)이 기반으로 사용한다.

**진행률** █████████████████░░░ 85%

## 사용자 플로우

1. 결재 상신/팀장 서명/최종 승인/반려 시 관련 사용자에게 알림 자동 발송
2. 헤더의 알림 벨에서 읽지 않은 알림 수(뱃지) 확인
3. 벨 클릭으로 드롭다운에서 알림 목록 조회 (타입별 색상/라벨)
4. 개별 읽음 처리 또는 "전체 읽음" 버튼

## 완료

- ✅ DB 기반 알림 저장 (Notification 모델)
- ✅ 알림 벨 UI (읽지 않은 수 뱃지, 상대 시간 표시)
- ✅ 읽음 처리 (개별/전체)
- ✅ 결재 워크플로우 알림 발송 (상신/팀장서명/최종승인/반려)
- ✅ 알림 타입별 색상/라벨 (APPROVAL_REQUEST/APPROVED/REJECTED/MA_EXPIRING/PAYMENT_DUE/SYSTEM)
- ✅ 링크 URL로 관련 문서 이동 (결제일 알림은 `/management/invoice-status?invoiceType=SALES|PURCHASE`로 통합 — 구 `/management/sales-invoice-status` 페이지 제거됨)

## 남은 것

- ⏳ 실시간 푸시/폴링 (현재 페이지 로드 시에만 조회, WebSocket/SSE 없음)
- ⏳ MA 만료 알림 (MA 계약 만료일 추적 모델 미구현)
- ⏳ 결제일 알림 (`notification-service.ts` 스케줄 로직 미완)

## 관련 화면

- 헤더 알림 벨 (전역 — `MainLayout`의 Header)
