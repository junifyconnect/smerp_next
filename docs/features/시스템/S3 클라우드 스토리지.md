# S3 클라우드 스토리지 🟡

AWS S3 기반 파일 관리 백엔드 서비스. 파일 탐색/업로드/삭제/다운로드 API가 구현되어 있으며, 견적서·품의서·발주서·서명 이미지 등 다른 기능의 첨부파일 기반으로 사용된다. 전용 브라우저 UI는 아직 없다.

**진행률** ██████████░░░░░░░░░░ 50%

## 제공 기능

- S3 폴더/파일 목록 조회
- 파일 업로드 (멀티파트)
- 파일 삭제
- presigned URL 기반 다운로드 (만료 시간 포함)

## 기반

- ✅ S3 파일 탐색 API (폴더/파일 분리)
- ✅ 파일 업로드 API
- ✅ 파일 삭제 API
- ✅ presigned URL 다운로드 API
- ✅ 영업/MA 문서의 파일 첨부에서 간접 활용 (`sales-quotes/[id]/files`, `sales-approvals/[id]/files`, `sales-orders/[id]/files`)
- ✅ 마이페이지 서명 이미지 업로드에서 사용

## 필요한 것

- ❌ 전용 파일 브라우저 UI (폴더 탐색, 드래그앤드롭 업로드, 파일 관리)
- ❌ 사이드바 "클라우드" 메뉴 항목 (추가 여부 미결정)

## 🤔 결정 필요

이 기능에는 기획 판단이 필요한 항목이 있습니다. → [결정 대기](../_결정대기.md#s3클라우드-브라우저ui)

## API 엔드포인트

- `GET /api/cloud` — 파일/폴더 목록
- `POST /api/cloud` — 파일 업로드
- `DELETE /api/cloud` — 파일 삭제
- `GET /api/cloud/download` — presigned URL 다운로드
