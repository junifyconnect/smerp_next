# 인증 🟢

사번 기반 로그인, 회원가입, JWT 세션 관리를 제공한다. NextAuth v5 beta의 Credentials provider로 구현되어 있으며 세션에 역할/부서/직급 정보가 포함된다.

**진행률** ████████████████████ 100%

## 사용자 플로우

1. 사번@servermate.net + 비밀번호로 로그인
2. 신규 직원은 회원가입 페이지에서 계정 생성
3. 로그인 후 JWT 세션(30일) 자동 유지
4. `/app/(main)/*` 접근 시 `MainLayout`이 세션 확인 → 미인증이면 `/login` 리다이렉트

## 완료

- ✅ Credentials 로그인 (bcrypt 비밀번호 비교)
- ✅ JWT 세션 (30일 만료)
- ✅ 회원가입 (/register)
- ✅ 비활성 계정 차단 (`isActive=false`)
- ✅ 세션에 역할/부서/직급 포함
- ✅ MainLayout 미들웨어 수준 인증 체크

## 남은 것

없음.

## 관련 화면

- `/login` (로그인)
- `/register` (회원가입)
