**상태**: 불명확 / 설계 공백

**문제**:
- 영업 품의서는 APPROVED 시 매출장·매입장 + 매출/매입 InvoiceRecord 자동 생성 (`BUSINESS_RULES.md` §5)
- MA 품의서는 APPROVED 시 `MAContract` + `MABilling` N건만 생성 → **원장/InvoiceRecord 미생성**
- 결과: MA 매출이 `경영 통계`, `계산서 발행 현황`에서 **영구 누락**. 회계 보고 정합성 깨짐
- 위치: `docs/features/MA/MA 품의서.md:26,41-43` vs `docs/features/영업/영업 품의서.md:28-32`

**선택지**:
- **A**: MA 승인 시에도 원장 + InvoiceRecord 자동 생성 (영업과 동일 처리 + `MAContract` 별도 보존)
- **B**: `MABilling`을 원장 대체 엔티티로 공식화 — 경영 통계/계산서 발행 현황에서 `MABilling`도 함께 집계하도록 API 개정
- **C**: MA는 별도 회계 라인으로 두고, 통합 집계는 하지 않음 (실무상 허용되는지 확인 필요)

**영향 범위**: MA 품의서, 경영 통계, 계산서 발행 현황, 매출장 매입장 (4개 기능)
