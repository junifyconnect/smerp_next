# 결정 대기 항목

기획 판단이 필요한 항목. 결정되면 해당 기능 파일에 반영한 뒤 여기서 제거됩니다.

항목 아래에 `**결정**: <선택지>` 또는 `**선택**: <선택지>` 라인을 추가하면 다음 `/project-spec:update`에서 감지해 반영을 시도합니다.

## S3 클라우드 브라우저 UI 필요 여부 {#s3클라우드-브라우저ui}

- **질문**: S3 파일 브라우저 전용 UI가 계획되어 있는가, 문서 첨부 백엔드로만 사용되는가?
- **선택지**:
  - A) 전용 파일 브라우저 페이지 (폴더 탐색, 업로드, 다운로드, 권한 관리)
  - B) 문서 첨부 기능에서만 간접 사용 (전용 UI 불필요)
- **영향**: A면 파일 브라우저 UI 개발 + 사이드바 메뉴 추가 + CLOUD 메뉴 권한(이미 정의됨) 연동 필요. B면 현재 상태 유지.
- **관련**: [S3 클라우드 스토리지](시스템/S3%20클라우드%20스토리지.md)
