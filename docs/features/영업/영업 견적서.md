# 영업 견적서 🟢

고객에게 제출할 영업 견적서를 작성하고 관리한다. 엑셀 업로드/다운로드, 버전 관리, 파일 첨부, 품의서 연동을 지원한다.

**진행률** ██████████████████░░ 90%

## 사용자 플로우

1. 견적서 목록에서 신규 작성 또는 엑셀 업로드로 견적서 생성
2. 고객사 선택 모달에서 매출처/담당자 지정
3. 제품 그룹과 품목을 추가하고 단가/수량 입력
4. 저장 후 엑셀 다운로드로 고객에게 전달
5. 수정이 필요하면 revise로 새 버전 생성 (이전 버전은 `isLatest=false`로 보존)

## 완료

- ✅ 견적서 CRUD (목록/상세/생성/수정/삭제)
- ✅ 검색, 상태 필터, 페이지네이션
- ✅ 엑셀 업로드 파싱 (exceljs)
- ✅ 엑셀 다운로드 생성
- ✅ 버전 관리 (revise, versions)
- ✅ S3 파일 첨부
- ✅ 고객사 선택 모달 (매출처 마스터 연동)
- ✅ 제품 그룹/품목 2단 구조

## 남은 것

- ⏳ 견적서 상태 변경 워크플로우 (SENT/ACCEPTED/REJECTED 전환 UI — DB status 필드는 있으나 전용 전환 UI 미구현)

## 관련 화면

- `/sales/quotes` (견적서 목록)
- `/sales/quotes/new` (신규 작성)
- `/sales/quotes/[id]` (상세 조회)
- `/sales/quotes/[id]/edit` (수정)
