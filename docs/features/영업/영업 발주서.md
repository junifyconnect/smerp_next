# 영업 발주서 🟢

매입처에 발주를 넣기 위한 발주서를 작성하고 관리한다. 상태 추적, 엑셀 업로드/다운로드, 버전 관리를 지원한다.

**진행률** ████████████████████ 100%

## 사용자 플로우

1. 발주서 목록에서 신규 작성 또는 엑셀 업로드
2. 매입처 자동완성으로 공급사 선택
3. 품목/수량/단가 입력 (SRP가 있으면 함께 기록)
4. 저장 후 엑셀 다운로드로 매입처에 전달
5. 상태 변경 (DRAFT → SENT → CONFIRMED → DELIVERED, 필요 시 CANCELLED)

## 완료

- ✅ 발주서 CRUD (목록/상세/생성/수정/삭제)
- ✅ 검색, 상태 필터, 페이지네이션
- ✅ 엑셀 업로드/다운로드
- ✅ 버전 관리 (revise, versions)
- ✅ S3 파일 첨부
- ✅ 상태 관리 (DRAFT/SENT/CONFIRMED/DELIVERED/CANCELLED)
- ✅ 매입처 자동완성 (`VendorAutocomplete`)

## 남은 것

없음.
