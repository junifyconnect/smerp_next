# 피그마 정보 추출 가이드

## 필수 확인사항

1. **레이아웃**: Flex, Grid, 절대 위치 등
2. **크기**: width, height, min/max 값
3. **간격**: padding, margin, gap
4. **색상**: 배경색, 텍스트색, 테두리색
5. **타이포그래피**: 글꼴, 크기, 굵기, 줄높이
6. **인터랙션**: hover, active, disabled 상태
7. **그림자 및 효과**: box-shadow, opacity
8. **아이콘/이미지**: 크기, 위치, 정렬

## Figma 도구 활용

- **Design Inspector** 활용하여 정확한 값 추출
- CSS 코드 내보내기 검토
- 컴포넌트 변형(Variants) 확인
- 모든 픽셀 값을 면밀히 살펴보기

## 확인 체크리스트

- [ ] 레이아웃 방식 확인 (flex/grid/absolute)

- [ ] 글꼴 정보 확인

- [ ] 반응형 breakpoint 별 디자인 확인
- [ ] 아이콘/이미지 소스 확인
