- **완료**: 실사용 가능 수준

## 우선순위별 정리

### 즉시 필요 (현재 작업과 직결)

1. **품의서 PATCH API 새 필드 반영** — category, taxType, invoiceUnit 등 수정 시 저장 안 됨
2. **품의서 edit 데이터 로딩 리팩토링** — old format → products 구조
3. **원장 목록 UI 페이지** — 매출/매입 원장 조회 화면 (API는 있음)
4. **원장 수동 등록/수정 API** — 품의서 없이 직접 기록하는 경비/임대 건

### 단기 (1~2주)

5. **대시보드 실데이터 연동** — stats API 연결만 하면 됨
6. **MA 품의서 3단계 결재** — 영업 품의서 패턴 복제
7. **품의서 → 발주서 연동** — 매입처별 자동 생성

### 중기 (3~4주)

8. **미수금/미지급금 관리** — Payment 모델 + CRUD + UI
9. **MA 계약 관리** — MAContract 모델 + 월간 자동 청구
10. **경영 대시보드 고도화** — 역할별 뷰, 차트

### 장기

11. 감사 로그
12. 엑셀 보고서 자동 생성
13. 발주서 발송/납품 확인 워크플로우
