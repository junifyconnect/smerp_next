# 02. AS-IS 업무 프로세스 (엑셀 기반 현행)

현재 서버메이트의 업무는 엑셀 파일 기반으로 운영되고 있다. 각 엑셀 파일이 어떤 업무를 담당하는지, 그리고 이 파일들이 어떻게 연결되는지 분석한다.

## 2.1 엑셀 파일 체계

### 영업 문서류

| 순서 | 문서 | 파일 위치 | 용도 |
|------|------|---------|------|
| 1 | 견적서 | `quotes_example.xlsx` | 고객에게 가격/스펙 제안 |
| 2 | 품의서 (Sales) | `planning/sales_approval/` | 내부 승인 (매출가+매입가 병기) |
| 3 | 발주서 | `planning/sales-order/` | 매입처에 구매 주문 |
| 4 | MA 견적서 | `planning/ma_quotation/` | 유지보수 서비스 가격 제안 |
| 5 | MA 품의서 | `planning/ma_approval/` | 유지보수 내부 승인 |

### 경영관리 문서류

| 번호 | 문서 | 파일명 | 용도 |
|------|------|-------|------|
| 1 | 품의/계산서 발행현황 | `1.품의_계산서발행현황.xlsx` | 품의별 매출/매입 계산서 추적 |
| 2 | 매출 원장 | `2.ERP_2025_매출.xlsx` | 월별 전체 매출 기록 (782건+) |
| 3 | 매입 원장 | `3.ERP_2025_매입.xlsx` | 월별 전체 매입 기록 (1,260건+) |
| 4 | 외상매입출금예정 | `4.월말_외상매입출금예정내역.xls` | 미지급금 추적 |
| 4' | 외상매출입금예정 | `4.월말_외상매출입금예정내역.xlsx` | 미수금 추적 |
| 5 | 매출 Rank | `5.매출_Rank.xlsx` | 거래처/담당자별 실적 순위 |

## 2.2 영업 프로세스 상세

### 일반 영업 (제품 판매)

```
Step 1: 견적서 작성
├── 고객 정보 (회사명, 담당자, 연락처)
├── 제품 목록 (P/N, 품명, 수량, 단가)
├── 합계 금액 (공급가액 + VAT)
├── 납기일, 결제조건, 유효기간
└── 파일명 규칙: "날짜(제품명)_매출처_담당자_견적서.xlsx"

Step 2: 품의서 작성 (고객 승인 후)
├── 품의코드 생성: D + 날짜6자리 + 순번 (예: D251206-01)
├── 좌측: 매출 정보 (고객에게 받을 금액)
│   ├── P/N, 품명, 수량, 매출단가, 매출합계
│   └── 매출처, END-USER
├── 우측: 매입 정보 (공급처에 낼 금액)
│   ├── 매입처, 수량, 매입단가, 매입합계
│   └── 매입일
├── 마진 자동 계산 (매출 - 매입)
├── 3단계 결재란 (영업담당 → 영업팀장 → 대표이사)
└── 파일명 규칙: "D날짜-순번_매출처(제품명)_품의서.xlsx"

Step 3: 발주서 작성 (결재 완료 후)
├── 매입처 정보 (회사명, 담당자)
├── 제품 목록 (P/N, 모델, S/N, 수량, 단가)
├── 납품 장소, 결제 조건
└── 파일명 규칙: "날짜(모델명)매입처_담당자.xlsx"

Step 4: 계산서 발행
├── 매출 계산서: 고객에게 청구
├── 매입 계산서: 공급처에서 수신
└── 발행 현황을 "1.품의_계산서발행현황.xlsx"에 기록

Step 5: 대금 관리
├── 입금 확인 → 매출 원장에 입금일 기록
├── 미수금 → "4.월말_외상매출입금예정내역.xlsx"에 기록
└── 미지급금 → "4.월말_외상매입출금예정내역.xls"에 기록
```

### MA (유지보수) 영업

일반 영업과 다른 점:

| 항목 | 일반 영업 | MA 영업 |
|------|---------|--------|
| 계약 기간 | 일회성 | 12~36개월 장기 계약 |
| 청구 | 1회 or 선입금 | 월간 정기 청구 (12회, 36회 등) |
| 대상 | 신규 제품 구매 | 기존 장비 기술지원/유지보수 |
| 수익 | 변동적 | 안정적 반복 수익 (MRR) |
| 관리 단위 | 프로젝트/건 | 고객/장비 단위 |
| 서비스 | 판매/납품 | 24x7 기술지원, SLA 보장 |

MA 견적서 특이사항:
- 장비별 기록: 기기명, M/T, Model, S/N, 서비스레벨
- 계약 기간: 시작일~종료일
- 월간 단가 × 12개월 = 연간 총액

MA 품의서 특이사항:
- SM코드, Vendor코드로 관리
- 매출 청구구분 / 매입 청구구분 별도 기록
- 매출처(고객사)와 고객사(END-USER) 구분

## 2.3 경영관리 프로세스 상세

### 매출 원장 (2.ERP_2025_매출.xlsx)

월별 시트 + Master 시트 + 분류 시트로 구성. 각 거래 기록:

| 필드 | 설명 | ERP 대응 |
|------|------|---------|
| 품의코드 | D251201-01 형식 | SalesApproval.approvalCode |
| Vendor 코드 | 매입처 식별코드 | 별도 관리 필요 |
| 날짜 | 거래일 | SalesLedger.transactionDate |
| 매출처 | 고객사 | clientCompany |
| END-USER | 최종 사용처 | endUser |
| 구분 | MA/상품/임대 등 | category |
| 거래내용 | 상세 설명 | description |
| 수량/단가/공급가액/VAT/합계 | 금액 정보 | 금액 필드들 |
| 매입액 | 원가 | purchaseAmount |
| GP | 마진율 | grossProfit |
| 입금일 | 실제 입금일 | paymentDate |
| 영업담당자 | 담당자 | managerName |

2025년 1~6월 기준: 월 매출 2.3~3.8억원 규모, 건수 115~117건/월

### 매입 원장 (3.ERP_2025_매입.xlsx)

매출 원장과 유사한 구조이나 추가 관리 항목:
- 결제방식: 자동이체, 현금 등
- 세금계산서 발행처 구분
- 비과세/영세 거래 구분
- 현금영수증/법인카드 거래 별도 시트

2025년 1~6월 기준: 월 매입 2.5~3.7억원 규모, 건수 194~212건/월

### 미수금/미지급금 (외상 관리)

월말에 작성하는 보고서:
- 날짜순/월별/거래처별 3가지 뷰로 정렬
- 입금예정일/출금예정일 추적
- 대표 확인용 별도 뷰

## 2.4 AS-IS 문제점

1. **데이터 중복/불일치**: 같은 거래를 여러 엑셀에 수동 입력 → 오류 발생
2. **추적 어려움**: 견적서 → 품의서 → 발주서 간 연결이 파일명에만 의존
3. **실시간 현황 불가**: 매출/매입 현황을 파악하려면 엑셀을 열어 직접 합산
4. **결재 지연**: 물리적 서명 또는 메신저를 통한 승인 → 추적 어려움
5. **버전 관리 부재**: 수정된 견적서/품의서의 이력 추적 불가
6. **접근성**: 사무실 PC에서만 작업 가능, 외근 시 불편
7. **보고서 생성 부담**: 월말 정산, 미수금 현황 등 수작업 보고서 작성에 시간 소모
