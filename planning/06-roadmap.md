# 06. 개발 로드맵

## 6.1 우선순위 기준

| 기준 | 설명 |
|------|------|
| 비즈니스 임팩트 | 현재 수작업 부담이 큰 업무 자동화 우선 |
| 데이터 연결성 | 다른 기능의 전제가 되는 기능 먼저 |
| 구현 난이도 | 기존 코드 기반으로 확장 가능한 것 우선 |
| 사용 빈도 | 매일 사용하는 기능 > 월 1회 사용 기능 |

## 6.2 Phase 1: 핵심 자동화 (최우선)

> 목표: 품의서 승인부터 원장 기록까지 자동 연동

### 1-1. 매출/매입 원장 자동 등록

- 영업 품의서 승인 완료 시 → SalesLedger, PurchaseLedger 자동 생성
- 기존 SalesLedger, PurchaseLedger 모델 활용
- 원장 목록 화면 (월별 조회, 필터, 검색)
- 원장 수동 등록/수정 기능 (일반경비, 임대료 등)

### 1-2. 계산서 발행 현황 강화

- 월별 계산서 발행 현황 대시보드 (현행 엑셀 "1.품의_계산서발행현황" 대체)
- 미발행 건 필터링 + 일괄 상태 업데이트
- 계산서 발행일/번호 입력 UI

### 1-3. 품의서 → 발주서 연동

- 품의서 매입 항목에서 발주서 자동 생성
- 매입처별 발주서 분리
- 발주서 목록에서 원본 품의서 바로가기

### 1-4. MA 품의서 결재 워크플로우

- MA 품의서에 3단계 결재 추가 (SalesApproval과 동일 패턴)
- 결재 알림 연동

### 1-5. UX 개선 (기존 기능 보완)

- 견적서 복사 기능 (기존 견적서 기반으로 새 견적서 빠르게 작성)
- 견적서 → 품의서 전환 UX 개선 (매입 정보 입력 단계 명확화)
- 견적서 검색/필터 강화 (고객사별, 기간별, 상태별, 담당자별)
- MA 견적서 → MA 품의서 전환 연동

**예상 작업량**: 3~4주

## 6.3 Phase 2: 미수금/미지급금 관리

> 목표: 월말 외상 현황 보고서 자동화

### 2-1. 미수금(AR) 관리

- 매출 원장 기반 미결제 건 목록
- 입금 처리 (전액/부분)
- 거래처별/월별/날짜순 정렬 뷰
- 입금예정일 관리
- 연체 하이라이트
- 엑셀 다운로드 (현행 "4.월말_외상매출입금예정내역" 양식)

### 2-2. 미지급금(AP) 관리

- 매입 원장 기반 미결제 건 목록
- 출금 처리
- 출금예정일 관리
- 엑셀 다운로드 (현행 "4.월말_외상매입출금예정내역" 양식)

### 2-3. Payment 모델 추가

- 입금/출금 기록 관리
- 부분 입금 시 잔액 자동 계산

**예상 작업량**: 2주

## 6.4 Phase 3: 경영 대시보드

> 목표: CEO/팀장이 실시간 경영 현황 파악

### 3-1. 대시보드 메인

- 요약 카드: 월 매출, 매입, GP, 미수금, 미지급금
- 월별 매출/매입 추이 차트 (recharts)
- 카테고리별 매출 비중 (MA vs 상품 vs 임대)
- 거래처 TOP 10
- 담당자별 실적

### 3-2. 역할별 대시보드

- CEO: 전체 현황 + 결재 대기 건
- 팀장: 팀 실적 + 결재 대기
- 담당자: 개인 실적 + 내 문서 현황

**예상 작업량**: 1~2주

## 6.5 Phase 4: MA 계약 관리

> 목표: MA 반복 매출 자동화

### 4-1. MA 계약 모델 및 화면

- MAContract, MAContractItem 모델 추가
- MA 품의서 승인 → 계약 자동 생성
- 계약 목록/상세 화면
- 장비 목록 관리

### 4-2. 월간 자동 청구

- 크론잡: 매월 활성 계약 → 매출 원장 자동 등록
- MABilling 이력 관리
- 청구 현황 대시보드

### 4-3. 만료 관리

- 만료 예정 계약 알림 (30/60/90일)
- 캘린더 이벤트 자동 생성
- 갱신 견적서 생성 유도

**예상 작업량**: 2~3주

## 6.6 Phase 5: 고도화

> 목표: 편의 기능 및 데이터 품질 강화

### 5-1. 거래처/매입처 강화
- 거래처별 통합 거래 이력
- 매입처 담당자 복수 관리 (VendorContact)
- 거래처별 미수금 현황 요약

### 5-2. 엑셀 보고서 고도화
- 매출 원장 엑셀 다운로드 (현행 양식 그대로)
- 매입 원장 엑셀 다운로드
- 매출 Rank 자동 생성

### 5-3. 발주서 고도화
- 발주서 발송 기능 (이메일 or 다운로드)
- 납품 확인 워크플로우 (발주 → 입고 확인 → 납품 완료)
- 발주서 ↔ 매입 계산서 연결

### 5-4. 장비 마스터 데이터
- 자주 사용하는 장비 정보 재활용 (MA 견적서/품의서에서 선택)

### 5-5. 알림/자동화 고도화
- 견적서 유효기간 만료 알림
- 미수금 연체 자동 알림
- 결재 독촉 알림 (3일 이상 미처리)
- 결재 진행상황 실시간 알림 강화

### 5-6. 감사 로그
- 문서 변경 이력 추적
- 접근 로그

**예상 작업량**: 2~3주

## 6.8 즉시 실행 가능한 Quick Win

기획과 별개로, 기존 코드에서 바로 개선할 수 있는 항목:

1. 품의서 승인 시 SalesLedger/PurchaseLedger 자동 생성 로직 추가 (API 수정)
2. MA 품의서에 결재 필드 추가 (스키마 마이그레이션)
3. 발주서에 sourceApprovalId 추가 (품의서 연결)
4. 대시보드 페이지에 기본 통계 카드 추가
5. 미수금/미지급금 조회 API (기존 원장 모델의 paymentStatus 필터링)
