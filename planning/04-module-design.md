# 04. 모듈 설계 (TO-BE)

## 4.1 영업 모듈 (Sales)

### 4.1.1 영업 견적서 (Sales Quote)

**현재 구현**: CRUD, 버전관리, 엑셀 업로드/다운로드, 파일첨부 ✅

**보완 필요**:

- 견적서 복사 기능: 기존 견적서를 기반으로 새 견적서 빠르게 작성
- 견적서 → 품의서 전환 UX 개선: 전환 시 매입 정보 입력 단계 명확화
- 견적서 검색/필터 강화: 고객사별, 기간별, 상태별, 담당자별
- 견적서 만료 알림: 유효기간 도래 시 알림

### 4.1.2 영업 품의서 (Sales Approval)

**현재 구현**: CRUD, 결재 워크플로우, 계산서 추적 ✅

**보완 필요**:

- 품의서 승인 시 매출원장(SalesLedger) 자동 등록
- 품의서 승인 시 매입원장(PurchaseLedger) 자동 등록
- 품의서 → 발주서 자동 생성: 매입처별로 발주서 분리 생성
- 결재 진행상황 실시간 알림 (현재 알림 모델 있으나 연동 확인 필요)
- 품의서 목록에서 계산서 발행 현황 한눈에 보기

### 4.1.3 영업 발주서 (Sales Order)

**현재 구현**: CRUD, 버전관리 ✅

**보완 필요**:

- 품의서 매입 정보 → 발주서 자동 생성 연동
- 발주서 발송 기능 (이메일 or 다운로드)
- 납품 확인 워크플로우: 발주 → 입고 확인 → 납품 완료
- 발주서와 매입 계산서 연결

## 4.2 유지보수 모듈 (MA)

### 4.2.1 MA 견적서

**현재 구현**: CRUD, 장비별 정보 ✅

**보완 필요**:

- MA 견적서 → MA 품의서 전환 연동
- 장비 마스터 데이터 관리 (자주 사용하는 장비 정보 재활용)

### 4.2.2 MA 품의서

**현재 구현**: CRUD, SM코드/Vendor코드 ✅

**보완 필요**:

- MA 품의서 결재 워크플로우 (현재 결재 없이 생성만 가능 → Sales와 동일한 3단계 결재 적용)
- MA 품의서 승인 시 MA 계약 자동 생성

### 4.2.3 MA 계약 관리 (신규)

**현재**: 미구현. MA 매출은 매출 원장 엑셀에서 월간 반복 기록으로만 관리.

**TO-BE 설계**:

```
MAContract (MA 계약)
├── 기본 정보
│   ├── 계약번호 (자동 채번)
│   ├── 고객사 (Customer 연결)
│   ├── 계약 기간 (시작일 ~ 종료일)
│   └── 상태: ACTIVE / EXPIRING / EXPIRED / CANCELLED
│
├── 장비 목록
│   ├── 기기명, M/T, Model, S/N
│   ├── 서비스 레벨
│   └── 월간 단가
│
├── 청구 정보
│   ├── 매출 총액 (월간 단가 × 장비수 × 계약 기간)
│   ├── 매입 총액 (공급처 비용)
│   ├── 청구 주기 (월간/분기/연간)
│   └── 청구 이력 (MABilling)
│
├── 갱신 정보
│   ├── 자동 갱신 여부
│   ├── 갱신 알림 (만료 30/60/90일 전)
│   └── 갱신 이력
│
└── 연결
    ├── MA 품의서 (승인된)
    └── 월별 매출 원장 기록
```

**자동화 포인트**:
- MA 품의서 승인 → MA 계약 자동 생성
- 매월 1일 → 활성 계약 기반으로 매출 원장에 월간 매출 자동 기록
- 계약 만료 30/60/90일 전 → 캘린더 이벤트 + 알림 자동 생성
- 계약 만료 → 갱신 견적서 생성 유도

## 4.3 경영관리 모듈 (Management)

### 4.3.1 계산서 발행 현황 (Invoice Status)

**현재 구현**: 품의서 기반 계산서 상태 조회 ✅

**보완 필요**:

- 월별 계산서 발행 현황 대시보드 (현행 "1.품의_계산서발행현황.xlsx" 대체)
- 매출/매입 계산서 분리 뷰
- 미발행 계산서 알림
- 계산서 발행일/번호 일괄 입력 기능

### 4.3.2 매출 원장 (Sales Ledger)

**현재**: DB 모델 존재, 화면 부분 구현

**TO-BE**:

데이터 소스:
- 영업 품의서 승인 시 → 자동 등록
- MA 월간 청구 시 → 자동 등록
- 수동 입력 (건물임대, 기타 매출 등)

핵심 화면:
- 월별 매출 목록 (현행 엑셀 월별 시트 대체)
- Master 뷰: 전체 기간 통합 조회
- 분류 뷰: 카테고리별(MA/상품/임대), 담당자별 집계
- 입금 상태 관리: 미수금 / 입금완료 / 부분입금

필터/검색:
- 기간 (월/분기/연도)
- 매출처 (거래처)
- 구분 (MA/상품/임대/기타)
- 담당자
- 입금 상태

### 4.3.3 매입 원장 (Purchase Ledger)

**현재**: DB 모델 존재, 화면 부분 구현

**TO-BE**:

데이터 소스:
- 영업 품의서 승인 시 매입 항목 → 자동 등록
- MA 월간 매입 → 자동 등록
- 수동 입력 (일반경비, 현금/법인카드 거래)

추가 관리:
- 매입 유형 구분: 세금계산서 / 현금영수증 / 법인카드 / 수입
- 결제 추적: 결제예정일, 실결제일, 결제방식
- 비과세/영세 구분

### 4.3.4 미수금 관리 (AR - Accounts Receivable) (신규)

**현행**: "4.월말_외상매출입금예정내역.xlsx"로 수동 관리

**TO-BE 설계**:

```
미수금 관리 화면
├── 미수금 목록
│   ├── 매출 원장 중 paymentStatus = PENDING/PARTIAL/OVERDUE
│   ├── 정렬: 거래처별 / 날짜순 / 금액순
│   └── 입금예정일 기준 연체 하이라이트
│
├── 입금 처리
│   ├── 전액 입금 → paymentStatus = COMPLETED
│   ├── 부분 입금 → paymentStatus = PARTIAL + 잔액 추적
│   └── 입금일 기록
│
├── 월말 보고서
│   ├── 거래처별 미수금 합계
│   ├── 월별 추이
│   └── 엑셀 다운로드 (현행 양식 호환)
│
└── 알림
    ├── 입금예정일 D-7 알림
    ├── 연체 알림 (D+1)
    └── 대표 확인용 요약 보고
```

### 4.3.5 미지급금 관리 (AP - Accounts Payable) (신규)

**현행**: "4.월말_외상매입출금예정내역.xls"로 수동 관리

**TO-BE**: 미수금 관리와 대칭 구조
- 매입 원장 기반 미결제 건 추적
- 출금예정일 관리
- 월말 보고서 (거래처별/월별)

### 4.3.6 경영 대시보드 (신규)

**현행**: 엑셀 "분류" 시트에서 수동 집계

**TO-BE 설계**:

```
대시보드
├── 요약 카드
│   ├── 이번 달 매출 / 전월 대비
│   ├── 이번 달 매입 / 전월 대비
│   ├── 이번 달 GP(마진) / 마진율
│   └── 미수금 총액 / 미지급금 총액
│
├── 차트
│   ├── 월별 매출/매입 추이 (12개월)
│   ├── 카테고리별 매출 비중 (MA vs 상품 vs 임대)
│   ├── 담당자별 매출 실적
│   └── 거래처별 매출 TOP 10
│
├── 테이블
│   ├── 최근 승인된 품의서
│   ├── 결재 대기 건
│   ├── 만료 예정 MA 계약
│   └── 연체 미수금
│
└── 접근 권한
    ├── CEO: 전체 대시보드
    ├── 팀장: 팀 실적 + 결재 현황
    └── 담당자: 개인 실적 + 내 문서 현황
```

## 4.4 공통 모듈

### 4.4.1 거래처 관리 (Customer)

**현재 구현**: 회사 + 담당자 CRUD ✅

**보완 필요**:
- 거래처별 거래 이력 조회 (견적/품의/매출 원장 통합)
- 거래처별 미수금 현황
- 거래처 검색 자동완성 (전화번호, 담당자명으로도 검색)

### 4.4.2 매입처 관리 (Vendor)

**현재 구현**: CRUD + 사용빈도 정렬 ✅

**보완 필요**:
- 매입처별 거래 이력 조회
- 매입처별 미지급금 현황
- 매입처 담당자 복수 관리 (현재 1명만)

### 4.4.3 알림 시스템

**현재 구현**: DB 모델 + 알림 벨 UI ✅

**보완 필요**:
- 결재 알림 자동 생성 연동 확인
- MA 만료 알림 자동 생성 (크론잡)
- 미수금 연체 알림 자동 생성
- 알림 설정 (사용자별 수신 여부)

### 4.4.4 엑셀 호환

**현재 구현**: 엑셀 업로드 파싱, 템플릿 관리 ✅

**보완 필요**:
- 매출 원장 엑셀 다운로드 (현행 양식)
- 매입 원장 엑셀 다운로드 (현행 양식)
- 미수금/미지급금 보고서 엑셀 다운로드
- 계산서 발행현황 엑셀 다운로드
- 품의서/견적서/발주서 엑셀 다운로드 양식 정확도 개선
