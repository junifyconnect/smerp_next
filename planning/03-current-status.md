# 03. 현재 시스템 구현 현황

## 3.1 구현 완료 모듈

### 인증/권한 시스템 ✅

- Credentials 기반 로그인 (이메일/비밀번호)
- JWT 토큰 + NextAuth 세션 관리
- 역할 기반 접근제어 (ADMIN, SALES_MANAGER, SALES_STAFF, MA_MANAGER, MA_STAFF, FINANCE)
- 메뉴별 세분화 권한 (NONE / READ / FULL)

### 영업 견적서 (Sales Quote) ✅

- CRUD (생성/조회/수정/삭제)
- 버전 관리 (revise → 새 버전 생성, 이전 버전 이력 조회)
- 상태 관리: DRAFT → SENT → ACCEPTED/REJECTED
- 제품 그룹 + 개별 품목 2단 구조
- 엑셀 파일 업로드 → 자동 파싱
- 엑셀 다운로드
- S3 파일 첨부

### 영업 품의서 (Sales Approval) ✅

- CRUD + 견적서 기반 자동 생성
- 품의코드 자동 채번 (D + 날짜 + 순번)
- 매출 + 매입 이원화 가격 관리
- 마진(이익) 자동 계산
- 3단계 결재 워크플로우 (담당자 → 팀장 → CEO)
- 전자 서명 (서명 이미지 S3 저장)
- 반려 + 사유 기록
- 버전 관리 (수정본 생성)
- 계산서 발행 상태 추적 (매출/매입 각각)

### 영업 발주서 (Sales Order) ✅

- CRUD
- 매입처 정보 관리
- 제품 목록 (P/N, 모델, SRP가, 단가)
- 상태: DRAFT → SENT → CONFIRMED → DELIVERED / CANCELLED
- 버전 관리
- 엑셀 다운로드

### MA 견적서 (MA Quote) ✅

- CRUD
- 장비별 정보 (기기명, M/T, Model, S/N, 서비스레벨)
- 계약 기간 (시작일~종료일)
- 엑셀 업로드/파싱

### MA 품의서 (MA Approval) ✅

- CRUD
- SM코드, Vendor코드 관리
- 매출/매입 청구구분 별도 관리
- 고객사/매출처 구분

### 경영관리 ✅ (부분)

- 계산서 발행 현황 조회 (영업 품의서 기반)
- 매출 원장 (SalesLedger) - DB 모델 존재
- 매입 원장 (PurchaseLedger) - DB 모델 존재

### 관리자 기능 ✅

- 사용자 관리 (생성/수정/권한 설정)
- 거래처(Customer) 관리 + 담당자(Contact)
- 매입처(Vendor) 관리
- 엑셀 템플릿 관리 (필드 매핑 설정)
- 휴가 관리

### 부가 기능 ✅

- 캘린더 (이벤트 생성, 참여자, 반복 설정, 알림)
- 알림 시스템 (결재 요청/승인/반려, MA 만료, 결제 예정)
- 마이페이지 (개인정보, 연차 조회)

## 3.2 DB 모델은 있으나 기능 보완 필요

| 모델 | 현황 | 필요 작업 |
|------|------|---------|
| SalesLedger | 스키마 존재 | 품의서 승인 시 자동 생성 로직, 월별 집계 화면 |
| PurchaseLedger | 스키마 존재 | 매입 자동 기록 로직, 결제 추적 화면 |
| InvoiceRecord | 스키마 + 기본 CRUD | 세금계산서 번호 연동, 수정/취소 이력 강화 |
| ExcelTemplate | 스키마 + 관리 UI | 다양한 양식 지원 확대, 파싱 정확도 개선 |

## 3.3 미구현 / 설계 필요 영역

| 영역 | 설명 | 우선순위 |
|------|------|---------|
| 미수금 관리 (AR) | 매출 건별 입금 추적, 연체 알림, 월말 보고서 | 높음 |
| 미지급금 관리 (AP) | 매입 건별 출금 추적, 지급 예정 알림 | 높음 |
| 경영 대시보드 | 월별 매출/매입 추이, GP 분석, 담당자별 실적 | 높음 |
| 매출/매입 원장 자동화 | 품의서 승인 → 원장 자동 등록 | 높음 |
| MA 계약 관리 | 계약 기간 추적, 만료 알림, 갱신 관리 | 중간 |
| 품의서 → 발주서 연동 | 품의서 매입 정보 → 발주서 자동 생성 | 중간 |
| MA 월간 자동 청구 | MA 계약 기반 월별 매출 자동 생성 | 중간 |
| 엑셀 보고서 자동 생성 | 현행 엑셀 양식 그대로 자동 생성/다운로드 | 중간 |
| 매출 Rank / 실적 분석 | 거래처별/담당자별 매출 순위 및 추이 | 낮음 |
| 감사 로그 | 문서 변경 이력, 접근 로그 | 낮음 |
